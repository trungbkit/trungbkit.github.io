Karen

HEAD → main v1.0.7

A local-first desktop Git client. No account, no cloud, no licence server.

  • A fast commit graph with its own lane layout, plus search by message, author, SHA, file path or content.
  • Stage or discard by file, hunk or single line. Interactive rebase and a built-in three-way merge tool.
  • An Undo button after every destructive action, and a reflog view to get back to any earlier state.
  • Optional AI with your own key: commit messages, conflict resolution, pull request review and commit summaries.
Built with
Tauri 2, Rust, React, TypeScript
Runs on
macOS, Windows, Linux

Smart Commit

git smartc

One command takes you from a dirty working tree to open pull requests.

  • Writes a Conventional Commits message from your diff, then commits and pushes.
  • Opens a pull request to each target branch, titled from the full diff against that branch.
  • Works with Claude, OpenAI or Gemini, whichever key you already have.
  • Each step runs only when there’s something to do. Flags only ever remove steps.
Built with
Node.js with zero dependencies, plus the gh CLI

VietNôm

live

Write Vietnamese in chữ Nôm, the script our ancestors used for centuries.

  • Type a sentence and get a Nôm character for each syllable. Swap any of them.
  • A dictionary of 16,615 characters, 6,281 readings and 209 radicals, with every source cited.
  • Breakdowns show which part of a character carries the meaning and which carries the sound.
  • Games to learn with: a daily guessing puzzle, a character builder and a calligraphy card maker.
Data from
Unihan, Wiktionary, chunom.org
